# Sopy

Локальный PWA-музыкальный плеер в стиле **Liquid Glass** с адаптивным интерфейсом под ПК и iPhone. Работает полностью офлайн, хранит медиатеку локально в браузере и подстраивает цвета интерфейса под обложку текущего трека.

🔗 **Демо:** [spoky31.github.io/Sopy](https://spoky31.github.io/sopy/)

---

## Возможности

* **Адаптивный интерфейс** — трёхколоночная сетка на ПК и мобильный режим с нижней навигацией и мини-плеером для iPhone.
* **Динамическая атмосфера** — размытый фон и градиент аудио-визуализатора автоматически подстраиваются под цвета обложки.
* **Эквалайзер** — 3-полосный EQ (Бас / Середина / Верх) и 5 пресетов (*Ровный, Bass Boost, Pop, Rock, Вокал*) с сохранением настроек.
* **Таймер сна** — автоматическая пауза через 15, 30, 45 или 60 минут с обратным отсчётом.
* **Синхронизированный текст** — поддержка таймкодов формата `[00:12]` с автопрокруткой и перемоткой по клику на строчку.
* **Локальная медиатека** — хранение аудиофайлов, обложек, исполнителей, текстов и «Избранного» в IndexedDB без сторонних серверов.
* **Очередь и управление** — перетаскивание треков (Drag & Drop), поиск по названию и исполнителю, горячие клавиши на ПК и управление с экрана блокировки iPhone (`MediaSession API`).

---

## Стек

* **Frontend:** HTML5, CSS3 (Glassmorphism / Liquid Glass), Vanilla JavaScript
* **Хранилище:** IndexedDB, `localStorage`
* **Аудио:** Web Audio API (`AnalyserNode`, `BiquadFilterNode`)
* **PWA:** Web App Manifest, Service Worker (офлайн-кэширование)

---

## Установка на iPhone

1. Откройте [spoky31.github.io/sopy](https://spoky31.github.io/sopy/) в **Safari**.
2. Нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.
3. Запускайте **Sopy** с рабочего стола в полноэкранном режиме.

## Горячие клавиши (ПК)

| Клавиша | Действие |
| :--- | :--- |
| `Space` | Пуск / Пауза |
| `←` / `→` | Перемотка на 10 секунд назад / вперёд |
| `↑` / `↓` | Громкость ±5% |
